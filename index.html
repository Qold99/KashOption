Before ordering

Practical checks before buying

The correct spark plug depends on more than the vehicle badge. Engine code, model year, regional specification and thread reach should be checked together.

Details that help identify the part

  • Vehicle make and model
  • Model year and market
  • Engine code or displacement
  • VIN or chassis number
  • Existing part number, if available

What to verify on receipt

  • Matching manufacturer and part number
  • Thread size and reach
  • Hex size and electrode type
  • Packaging and printed identification
  • Correct quantity for the engine

Technical guides

Spark plug knowledge centre

Guide 01 — Part identification

How to identify a spark plug reference

Start with the vehicle engine code and remove the existing plug if it is safe to do so. Record the manufacturer’s printed part number, thread size, reach and hex type. These details help distinguish visually similar plugs.

Guide 02 — Material types

Why plug construction differs

Spark plugs use different electrode and precious-metal combinations for different engine designs and service intervals. The factory specification should take priority over a general preference for one material.

Guide 03 — Heat range

Understanding heat-range requirements

Heat range and electrode reach are selected for a particular engine. Do not change either specification without a documented manufacturer reference or qualified technical advice.

Guide 04 — Fitment

Why VIN matching matters

Vehicles with the same model name can use different engines depending on year and assembly market. A full VIN or chassis number reduces ambiguity and helps check the exact factory specification.

Frequently asked questions

Buying and fitment questions

What details should I send for a fitment check?

Send the make, model, year, engine code or engine size and, if available, the complete VIN or chassis number.

Why may one model have more than one spark plug reference?

Engines and assembly specifications can differ between production years and markets. The engine code is more reliable than the model name alone.

Does this catalogue show live inventory?

The catalogue is a product-reference page. Use the WhatsApp enquiry link to confirm current stock and price before placing an order.

Can you quote workshop or retailer quantities?

Yes. Include the required brand, part number, quantity and delivery location in a trade enquiry.

How can I confirm delivery timing?

Send the destination and required quantity to the WhatsApp line so the team can confirm the available dispatch method and timing.
